A look at the whole journey and whats left to do along with how i worked on the project.
PLANNING, I was thinking on making a retro style arcade type game for a while, but something actually challenging and fun for past few weeks now, and stardance finlly moved me to do it. I opened a fresh ai chat told it about my ideas and used that chat to ONLY decide on features, implementation route and how I would continue building
STARTING WORK, Used a AI agent to develop some base line code to see how all the features would be built out and how i would work on implementong the features. i closely examined the code, then openend a new folder in my ide and began to create the entire file directory and structure for the frontend and puzzles and css styling.
BUILDING & DEBUGGING,I used the files the agent made to write out the base code frame from where i edited the styling and adjusted some features to make the game actually playable cuz agents never do any work right. ran into some issues with the shifting between different sectors due to bugs in the main App.jsx file.
TESTING AND DEPLOYMENT, I spent a good deal of time (30 minutes... def a great deal) to beat the game and make sure no other sectors were buggy. after being assured, i pushed the code to Github and deployed the app on vercel, giving it to my close friends for testing and their reviews as well.
